# Sources and methodology — Maldives Fishing and Holiday Pvt Ltd (MFH)

Unlike the rest of `data/maldives/fishing/`, this data was **not** compiled via web
search — it comes directly from two owner-supplied PDF rate sheets, both explicitly
"Valid Until: 31 December 2027":

- `MFH_Charter_Rate_sheet_.pdf` (5 pages)
- `MFH_Packages_Rate_sheet_.pdf` (5 pages)

Both documents are issued by **Maldives Fishing and Holiday Pvt Ltd**, trading as
"Maldives Fishing and Holidays Lodge", Athirifinivaage, Ga. Maamendhoo, Maldives.
Registration `C40602025`. Managing Director: Safooh Ali.
Contact: +960 7444509 / safooh@maldivesfishing.com / www.maldivesfishing.com.

## Website pricing rule

Every selling price on this site is the **source PDF price minus USD 20**, applied
mechanically (never hand-typed) in
`/tmp/.../scratchpad/mfh-pricing.py` at ingestion time, then carried unchanged
through `mfh-charters.json` / `mfh-packages.json` as `price_from` (website) and
`price_from_source` / `guest_pricing[].sourcePrice` (the original PDF figure) —
`scripts/generate-mfh-seed.mjs` only ever reads these two fields, it never
recomputes the subtraction, so the DB and the PDF can never silently drift apart.

The $20 reduction was applied **only** to genuine per-trip/per-person selling
prices (the 2 charter rates, the 70 package guest-tier prices). It was
**deliberately not applied** to any add-on/extra line item from either PDF
(Domestic Transfer $475/person, Equipment Rental $80/kit, FB meals & hotel
$150/room, Professional Rod & Reel Setup $80/setup) — the task brief's own
instruction warned against altering a provider's non-headline costs without
clear evidence the rule was meant to apply there, and neither PDF's own $20-off
examples ever referenced an add-on. These add-on figures are not currently
surfaced on the site (see "Known gaps" below).

## `mfh-charters.json` — 2 entries

Both are the boat's genuine, named commercial products from the Charter Rate
Sheet (pages 3-4): a Private Full-Day Charter (USD 1,400 → website USD 1,380)
and a Private Half-Day Charter (USD 1,000 → website USD 980), both "per boat",
aboard "Emperor", a real 32-foot fishing boat with twin 200 HP engines (max 5
passengers) pictured across both PDFs. No fishing-technique-specific charter
products (e.g. a separately-priced "Big Game Fishing Charter" or "Tuna Fishing
Charter") were created — the source material describes exactly one boat/crew/
price for each day-length, with "basic fishing gear" included generically, not
per technique. Fabricating technique-specific SKUs with invented prices would
violate the task's explicit no-fabrication rule. Individual fishing techniques
(big game, reef, trolling, jigging, popping, handline) are instead covered as
genuinely real, already-existing tagged `activities` rows elsewhere in this
directory (`activities.json`) and surfaced as descriptive content on the
Fishing hub page, each linking back to these same 2 real charter products.

## `mfh-packages.json` — 14 entries

The Packages Rate Sheet's two guest-pricing tables (page 3: Full-Day Fishing
Rates, page 4: Half-Day Package Cost) each cover 7 durations (2-8 nights) at 5
guest-sharing tiers (1-5 guests) — 70 individual price points total. Per the
task brief's explicit "package product / duration-guest variants / pricing
table" architecture guidance (not one generic page, not 70 separate thin
pages), this became **14 real packages** — one per (duration x day-type)
combination, since a 2-night trip and an 8-night trip are genuinely different
holiday products — each carrying the full 1-5 guest pricing table as
structured data (`guest_pricing[]`), not as 5 additional separate packages.

`packages.price_from` (a single-number DB column) is set to the lowest
verified per-person rate for that package — the 5-guest "Best Value" tier, per
the PDF's own labeling. The complete 1-5 guest table is exposed separately via
`src/lib/packages/mfh-price-tables.ts` (generated by the same script, from the
same source JSON, so it can never drift from `price_from`) rather than via a
new migration/table, since a one-off 2-dimensional pricing table for a single
operator did not seem to justify a schema change.

## Accommodation and provider

"Maldives Fishing and Holidays Lodge" is seeded as a real `guesthouse`
accommodation (both PDFs describe and photograph real guest rooms, full-board
meals, max 2 guests/room) at **Maamendhoo, Gaafu Alifu Atoll** — an island that
already existed in `data/maldives/locations/islands.json` before this task
(distinct from a second, unrelated island of the same name in Laamu Atoll; the
Gaafu Alifu one, slug `maamendhoo-gaafu-alifu`, was resolved by exact
name+atoll-code match, never guessed). "Maldives Fishing and Holiday Pvt Ltd"
is seeded as a real, verified `providers` row (website, contact email/phone,
legal name, and license/registration number all taken directly from the PDFs'
own footer, `is_verified = true` since this is a primary-source rate sheet,
not a scraped listing).

## Itinerary composition

Each of the 14 packages gets a 2-stage itinerary: Stage 1 (accommodation +
the matching charter activity, quantity = the package's own `fishing_days`)
covering the full stay, Stage 2 (departure — boat transfer + return domestic
flight, per both PDFs' identical "How It Works" section). No return-transfer
`transfer_service` row exists in this dataset for Maamendhoo, so Stage 2 is
described in plain text rather than referencing a fabricated transfer
service — same rule already applied in `data/maldives/packages/SOURCES.md`.

## Known gaps

- **Add-on/extra pricing (domestic transfer, equipment rental, FB meals for
  non-package guests, professional rod & reel rental, 5-star resort transfers)
  is not yet surfaced anywhere on the site.** Both PDFs document these, but
  they are optional extras layered onto a booking rather than a distinct
  bookable product with its own page, and were out of this task's scope to
  turn into a full add-ons UI. The rate sheets' own figures are preserved
  here in full for a future task to wire in.
- **No return-to-airport transfer_service row exists** for Maamendhoo (same
  gap already documented for the original 6 real packages) — Stage 2 of
  every MFH package is text-only rather than a linked transfer.
- **"5 Star Resorts" add-on pricing is "TBA" / "To Be Advised" in both PDFs**
  — left out entirely rather than guessed, per the no-fabrication rule.
- **Fishing-technique-specific charter products were not created** (see
  `mfh-charters.json` section above) — this is a deliberate scope decision,
  not an oversight, and is documented on the Fishing hub page itself as
  content (not fabricated commercial SKUs) covering those keywords instead.
