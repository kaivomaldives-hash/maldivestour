The data for each target is in `04-keyword-url-mapping.csv`, `05-blog-content-roadmap.csv`, `07-image-production-plan.csv` and `08-internal-linking-plan.csv`.
Keyword metrics are all `Not available` (see the legend in doc 03).

## Rules for every brief

- Use only prices, inclusions and specs from the rate sheet, live product records or the owner. Never invent catches, sizes, reviews or awards.
- Never present a photo from the media bucket as a specific named trip unless the owner confirms it. Never present stock or illustrations as our own photos.
- Title tag ≤ 60 characters ("| MTG" suffix); meta description 120–155 characters; exactly one H1.
- FAQPage JSON-LD only for questions answered visibly on the page. No Review or AggregateRating markup.
- Translation: after the English version is approved, use the existing de/es/it/ru/ja/zh pipeline.
