## Re-planning triggers
Re-plan if any of these happen:
- GSC shows a query cluster at positions 5–20 with real impressions. Pull its target forward.
- A new page starts taking impressions from an existing page for the same query (cannibalization). Pause and resolve it (doc 11 §5).
- The owner can't supply an input (photos, specs). Move the item back; don't publish it with placeholders.
