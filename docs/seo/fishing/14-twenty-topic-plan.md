# 14 — Owner's 20-topic plan (adopted 2026-10-25)

The owner's list of 20 blog topics replaces the 13-article list in doc 05/10 as the content plan.
Each topic is mapped to one URL so that no two pages target the same search.
The page updates from doc 06 (U01–U19) still apply where a topic lands on an existing page.

## Rules for every topic
- **Put us in the topic.** Every article features the Maldives, Gaafu Alifu Atoll, Emperor and the Maldives Fishing and Holidays Lodge on Maamendhoo wherever they fit. Global topics (#12–#14) list the Maldives and Gaafu Alifu as a destination in their own right, with our offer.
- **Use our real listings.** Link and embed the real charters and packages (`<!--listing:activity:SLUG-->` / `<!--listing:package:SLUG-->` in database articles; charter cards and package tables on code pages). Prices only from the live records / `mfh-price-tables.ts` / owner confirmations.
- **Keywords in headings.** H2s use the phrases people search, not internal names.
- **Photos.** Use photos already in the media bucket; the same photo can appear in different articles; fix titles and alt text to describe what each photo shows.
- Nothing is published without owner sign-off. Database articles go in as drafts.

- **#12 vs #11:** #11 is the head-to-head; #12 lists many destinations and links to #11.
